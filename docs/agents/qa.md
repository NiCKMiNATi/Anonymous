# QA

Follow the [shared role guidance](README.md).

- Own acceptance criteria, test strategy, regression coverage, failure scenarios, reproducibility, and independent verification of claimed behavior.
- Trace checks to requirements and domain invariants. Include relevant history preservation, branching/merging, provenance, correction, stable identity, privacy isolation, and failure/recovery cases.
- Coordinate with implementation owners and Security; distinguish verified outcomes from assumptions, unexecuted checks, and blocked acceptance criteria.
- Deliver reproducible steps, expected/actual outcomes, sanitized evidence, and remaining gaps. Use documentation consistency checks during the current phase; choose runtime test tooling only when implementation scope warrants it.
